# Jackal Box

Микро-DAW / драм-машина для себя: удобный степ-секвенсор с кнопками как у железных драм-машин, нарезка брейков, запись гитары через ASIO, хостинг VST3 и встроенные «цифровые шакалы» (bitcrush, codec, glitch).

Статус: MVP готов (этап 5 из 5). Песня из паттернов A–H (до 32 записей с повторами), экспорт WAV мастера и стемов быстрее реального времени, MIDI learn для любых ручек и кнопок, захват сыгранного задним числом; VST3-эффекты с компенсацией задержки, гитарная полоса и петли гитары длиной в паттерн; ШАКАЛ-цепь (шесть эффектов, пресеты IRON, NET, MEM) на каждой дорожке, мастере и гитаре; драм-машина 8×16 с ратчетами, вероятностью, условиями и p-locks, брейк-дорожка со слайсами, восемь глитч-пэдов, «Мутация», свинг, запись с MIDI и клавиатуры в шаги, проекты с автосохранением, процедурный демо-кит.

## Что внутри

- Драм-машина 8 строк × 16 кнопок, p-locks, ратчеты, вероятность, филл, своя длина строки (готово).
- Брейк-дорожка: слайсинг любых петель, включая гитару (готово для сэмплов).
- Глитч-пэды и кнопка «Мутация» (готово).
- ШАКАЛ-цепь на каждой дорожке и мастере (готово).
- Гитара через ASIO: петли длиной в паттерн, REC, DUB, UNDO, перенос петли в дорожку (готово).
- VST3-эффекты в слотах с компенсацией задержки (готово). MIDI-вход и запись в шаги (готово).
- Песня: цепочка паттернов с повторами, режимы PTN и SONG, FOLLOW (готово).
- Экспорт WAV мастера и стемов, офлайн, без звука в колонках (готово).
- MIDI learn: любой контроллер на ручки, кнопки, пэды и транспорт (готово).

## Стек

C++20, CMake, [JUCE 8](https://juce.com) (VST3-хостинг, ASIO), Windows + MSVC.

## Лицензии зависимостей

- JUCE 8: AGPLv3 или коммерческая.
- VST3 SDK: MIT (с версии 3.8).
- ASIO SDK: GPLv3 или проприетарная от Steinberg.


## Сборка

Windows (VS 2022 или новее, CMake сам найдёт установленную студию):

```
cmake -B build -A x64
cmake --build build --config Release
```

ASIO включается, если указать путь к ASIO SDK от Steinberg: `-DJACKAL_ASIO_SDK_DIR=C:/sdk/asiosdk_2.3.3` или переменная окружения `ASIO_SDK_DIR`. Без SDK приложение работает через Windows Audio / DirectSound.

Только движок и тесты (Linux или Windows, без JUCE):

```
cmake -B build -DJACKAL_BUILD_APP=OFF
cmake --build build
ctest --test-dir build --output-on-failure
```

Настройки хранятся в `%APPDATA%\JackalBox\JackalBox.xml`.

## ШАКАЛ

Цепь на каждой дорожке и на мастере, порядок фиксирован: Drive → SP-12 → Decimator → Bitcrush → Bitflip → GlitchBuffer. Одна ручка SHAKAL плюс пресет характера; ручные параметры эффектов во вкладке FX. Зажатый шаг плюс ручка SHAKAL ставит p-lock: ломается только этот удар.

| Эффект | Что делает |
| --- | --- |
| Drive | перегруз АЦП: клип или переполнение (wrap) до 36 дБ |
| SP-12 | 26 кГц, 12 бит, выходной фильтр 4-го порядка |
| Decimator | sample-and-hold до 500 Гц, без фильтра |
| Bitcrush | 1–16 бит, линейно или μ-law |
| Bitflip | XOR бита int16, по сэмплам или пачками по 64 |
| GlitchBuffer | заикание, реверс, повтор клетки по сетке 1/16 |

| Пресет | Характер |
| --- | --- |
| IRON | умирающий сэмплер: фильтр, разрядность, частота, перегруз, редкие флипы |
| NET | плохая связь: телефонная частота, μ-law, короткие повторы, пачки флипов |
| MEM | битая память: заикания, флипы старших битов, wrap |

`RR` (reroll) меняет сид проекта: другая раскладка глитчей, флипов и вероятностей шагов.

## VST3

Вкладка `VST` справа или слоты в гитарной полосе: клик по `+` открывает браузер плагинов. При первом запуске список пуст: `SCAN` ищет `.vst3` в `Common Files\VST3` и в папках из настроек (`ADD FOLDER…`). Каждый файл сканируется в отдельном процессе: если плагин падает или висит дольше 60 с, он попадает в чёрный список (`CRASHED`), остальные находятся. `RESCAN` пересканирует всё, включая чёрный список. Список хранится в `%APPDATA%\JackalBox\plugins.xml`.

Проверка чёрного списка без падающего плагина: запустить с переменной окружения `JACKAL_SCAN_CRASH_ON=<часть имени файла плагина>` и нажать `RESCAN`.

Инструменты VST3 не грузятся (после MVP). Задержка плагинов компенсируется до 16384 сэмплов, строка `PDC` во вкладке `VST`.

## Гитара и петли

Полоса под сеткой: `GAIN`, `GATE`, `HPF`, два слота (амп-сим), `SHAKAL` гитары, волна петли текущего паттерна, `REC`, `DUB`, `UNDO`, `BARS 1/2/4`, `TAP DI/AMP`, `LOOP`, `→TRK`. Запись стартует на следующем цикле паттерна, пока идёт отсчёт, звучит клик. Петля пишется с поправкой на задержку интерфейса и плагинов: `AUDIO/MIDI` → `LOOP TIMING` (задержка драйвера, ручная поправка, `CAL` меряет кабелем с выхода во вход). Файлы петель лежат в `loops/` внутри проекта.

## Песня

Строка под паттернами: `PTN | SONG`, `FOLLOW`, `LOOP`, 32 ячейки, `CLEAR`, счётчик. В `PTN` всё как раньше: клик по A–H ставит паттерн в очередь. В `SONG` играет строка ячеек, а клик по A–H только выбирает паттерн для правки; `FOLLOW` держит правку на играющем паттерне (ручной выбор другого его выключает, `O` включает обратно).

| Жест в строке песни | Что делает |
| --- | --- |
| клик по `+` | добавить редактируемый паттерн в конец |
| клик по ячейке | курсор; при игре в `SONG` прыжок на границе цикла |
| двойной клик | править паттерн этой ячейки |
| колесо / `Ctrl`+колесо | повторы 1–16 / буква A–H |
| протяжка | переставить запись |
| ПКМ или `Delete` | удалить запись |
| `Shift`+клик по ячейке | вставить редактируемый паттерн перед ней |
| `Shift`+клик по A–H, `Shift+F1..F8` | добавить паттерн в конец песни |

Правки песни отменяются `Ctrl+Z`. Без `LOOP` песня в конце останавливает транспорт (`END` в верхней строке).

## Экспорт

`EXPORT` внизу справа или `Ctrl+Shift+E`: песня или паттерн × N циклов, частота (как у устройства, 44100, 48000, 96000), 16 / 24 / 32f бит, стемы, хвост 0–8 с. Рендер идёт в отдельном потоке на своей копии проекта и плагинов, играть и править можно дальше. Файлы: `Имя.jackal/export/Имя_ГГГГММДД-ЧЧММСС/master.wav` и `stems/01_KICK.wav … 09_GUITAR.wav` (тихие стемы не пишутся); папку можно сменить кнопкой `…`. Стемы снимаются до мастера: без мастер-ШАКАЛ, глитч-пэдов, мастер-вставок и гейна. Пока петля гитары пишется, экспорт недоступен.

## MIDI

`AUDIO/MIDI` → `MIDI`: устройство, канал (`OMNI` или 1–16), ноты C..G любой октавы на дорожки 1–8, список привязок. Learn: `Ctrl+L` (или `LEARN`), клик по ручке или кнопке, покрутить ручку или нажать пэд на контроллере. То же из меню по правому клику на любой ручке или кнопке (там же `Clear MIDI`). Привязанные элементы отмечены точкой в левом верхнем углу. Пэды контроллера на удары дорожек: кнопки `+ TRACK HIT 1..8`. Привязка хранится к конкретной дорожке (`T3 SHAKAL`), а не к выбранной. Карта лежит в `%APPDATA%\JackalBox\midimap.json` и общая для всех проектов. Ноты пэдов и ударов играет сам движок, без задержки интерфейса.

`Ctrl+Shift+R` захватывает задним числом удары последних двух тактов (клавиши, мышь, MIDI) в играющий паттерн, даже если запись не была включена.

## Проект

Папка `Имя.jackal/` с `project.json` (формат `jackal-project`, версия 5; версии 2–4 открываются и при сохранении становятся 5, в строке статуса `project upgraded to v5`), `samples/` с импортированными WAV/AIFF, `loops/` с петлями гитары и `export/` с экспортом. Папку можно переносить целиком. Новые проекты лежат в `Документы\JackalBox\Projects`. Автосохранение каждые 30 секунд и при выходе.

## Клавиши

| Клавиши | Действие |
| --- | --- |
| `Space` | Play / Stop |
| `Ctrl+R` | запись (удары ложатся в шаги) |
| `0` (зажать) | Fill |
| `Q W E R T Y U I` / `A S D F G H J K` | шаги 1–8 / 9–16 выбранной строки |
| `Z X C V B N M ,` | живой удар дорожек 1–8 (с `Shift` громче) |
| `1`–`8` (зажать) | глитч-пэды |
| `F1`–`F8` | паттерн A–H: в `PTN` со следующего такта, в `SONG` только выбор для правки |
| `Shift+F1`–`F8` | добавить паттерн A–H в конец песни |
| `P` | `PTN` ↔ `SONG` |
| `O` | `FOLLOW` вкл/выкл |
| `↑ ↓` | выбор строки |
| `Ctrl+↑` / `Ctrl+↓` | предыдущий / следующий сэмпл из папки, откуда он импортирован |
| `← →` / `Alt+← →` | сдвиг строки / микросдвиг |
| `PageUp` / `PageDown` | страница сетки |
| `Ctrl+D` | удвоить паттерн |
| `Ctrl+M` | Мутация |
| `Ctrl+Z`, `Ctrl+Y` | undo, redo |
| `Ctrl+C`, `Ctrl+V` | копировать / вставить паттерн |
| `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+O`, `Ctrl+N` | сохранить, сохранить как, открыть, новый |
| `Delete` | над ячейкой песни: удалить запись; над шагом: убрать его p-locks |
| `Tab` | вкладки правой панели SRC · FX · VST · STEP · MST · GTR |
| `Enter` | петля: нет петли → REC, есть → DUB, во время отсчёта → отмена |
| `Shift+Enter` | новая петля поверх старой (старая уходит в историю) |
| `Backspace` | UNDO слоя петли |
| `Ctrl+P`, `Ctrl+Shift+P` | браузер плагинов для дорожки / для гитары |
| `Ctrl+E` | окно редактора последнего тронутого слота |
| `Ctrl+Shift+E` | экспорт |
| `Ctrl+L` | MIDI learn |
| `Ctrl+Shift+R` | захват последних двух тактов |
| `Esc` | отменить learn, затем закрыть окно плагина, затем оверлей |

Мышь на сетке: клик ставит или снимает шаг, протяжка по строке рисует, протяжка вверх-вниз на шаге меняет громкость, ПКМ стирает. Колесо: громкость; `Alt` ратчет, `Ctrl` слайс или питч, `Shift` вероятность. `Alt+клик` реверс, `Ctrl+клик` условие, `Shift`+протяжка рампа громкости. Зажать шаг на четверть секунды и крутить ручку справа: p-lock.

MIDI: ноты C..G любой октавы играют дорожки 1–8 (выключается в `AUDIO/MIDI` → `MIDI`), остальное через learn.
